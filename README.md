# Quiz Application

A responsive multiple-choice quiz application built using HTML, CSS, and JavaScript.

## Features

- Display questions
- Multiple-choice answers
- Select an answer
- Next question
- Score tracking
- Final result
- Restart quiz
- Random questions
- Difficulty levels
- Categories
- Timer

## Technologies

- HTML5
- CSS3
- JavaScript
